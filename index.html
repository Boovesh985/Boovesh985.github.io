Steel
E-Commerce

Industrial steel, ordered the way you'd order anything else online.

TMT bars, pipes, sheets and structural sections: 270+ real listings priced by the kilo. One React codebase ships as both a website and a native Android app.

Agentic AI · Healthcare

Multi-Agent
Clinical Reasoning

Five agents that check each other's work before anyone reads the answer.

A planner, researcher, reviewer, refiner and advisor, orchestrated with LangGraph. If an answer scores under 7/10 in review, it goes back for refinement before it reaches the user.

  • Cache-augmented generation: a question more than 88% similar to one already answered skips the pipeline and comes back instantly.
  • Retrieval runs over 100+ curated medical documents across 18 specialties with FAISS and MiniLM embeddings.
  • Evaluation endpoints score answer correctness and retrieval quality separately.

Deep learning · 1D-CNN · Encrypted ECG

Encrypted
ECG Diagnosis

A 1D-CNN that diagnoses heartbeats it never sees in plaintext.

A 1D-CNN classifies heartbeats from the MIT-BIH dataset into five arrhythmia classes. Cloud inference runs on CKKS-encrypted data, and SHAP and Grad-CAM explain every call.

  • 95.66% test accuracy and 0.9517 weighted F1, beating the base paper's 94.2%.
  • The server runs an encryption-friendly network (folded batch-norm, x² activation) and keeps 92.5% accuracy on ciphertext.
  • Built by a team of three. A live Streamlit app walks through encrypt → infer → decrypt → explain.
Model
1D-CNN, 3 Conv1D blocks (TensorFlow)
Data
MIT-BIH, 109,446 beats, 5 classes
Encryption
CKKS via TenSEAL, 128-bit
Explainability
