Steel
E-Commerce

Industrial steel, ordered the way you'd order anything else online.

TMT bars, pipes, sheets and structural sections: 270+ real listings priced by the kilo. One React codebase ships as both a website and a native Android app.

Agentic AI · Healthcare

Multi-Agent
Clinical Reasoning

Five agents that check each other's work before anyone reads the answer.

A planner, researcher, reviewer, refiner and advisor, orchestrated with LangGraph. If an answer scores under 7/10 in review, it goes back for refinement before it reaches the user.

  • Cache-augmented generation: a question more than 88% similar to one already answered skips the pipeline and comes back instantly.
  • Retrieval runs over 100+ curated medical documents across 18 specialties with FAISS and MiniLM embeddings.
  • Evaluation endpoints score answer correctness and retrieval quality separately.

Privacy-preserving ML · Cardiology

Encrypted
ECG Diagnosis

Classifying heartbeats on a server that never sees them.

ECG signals are encrypted on the patient's device with CKKS homomorphic encryption. A 1D-CNN classifies them in the cloud without decrypting, and SHAP explains the result to the clinician.

  • Convolutions are fused into matrix operations so inference runs directly on ciphertext.
  • Extends Cenitta et al. (IEEE Access, 2025) with cross-dataset generalisation and risk-adaptive encryption analysis.
  • A Streamlit dashboard walks through each step: plaintext, encrypt, infer, explain.
Accuracy
95.66% on MIT-BIH, 5 classes
Encryption
CKKS via TenSEAL, 128-bit security
Latency
~420 ms encrypt → infer → decrypt
Explainability
SHAP over 45 clinical features
Stack
TensorFlow, TenSEAL, SHAP, Streamlit
